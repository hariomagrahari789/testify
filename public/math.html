Chapter 1: Algebra

Short Notes

Polynomials

  • Quadratic Equations: ax² + bx + c = 0 solved using quadratic formula.
  • Polynomial Functions: Degree determines the number of roots.
  • Factoring: Techniques for factoring different polynomials.
Quadratic Formula: \( x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \)

Exponents and Logarithms

  • Exponent Rules: aᵐ × aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ, a⁻ᵐ = 1/aᵐ
  • Logarithm Properties: log(ab) = log a + log b, log(a/b) = log a - log b
  • Exponential Growth/Decay: Applications in real-world problems.
Change of Base: \( \log_b a = \frac{\log_k a}{\log_k b} \)

Matrices and Determinants

  • Matrix Operations: Addition, subtraction, multiplication.
  • Inverse Matrix: Finding inverse using adjoint and determinant.
  • System of Equations: Solving using matrix methods.
Inverse Matrix: \( A^{-1} = \frac{1}{\det(A)} \cdot \text{adj}(A) \)
